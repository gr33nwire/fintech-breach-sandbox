Phase 1: Attack Vector

Developer Pushes API Keys to Public GitHub Repository

A junior cloud engineer at Apex Pay accidentally commits an AWS credentials file containing `AKIA...` hardcoded access keys into a public GitHub repository while fixing a production bug late at night.

Attacker Automated Scanner Picks Up Credential

Within 45 seconds, malicious automated web scrapers detected the exposed AWS Access Key. The attacker verified the credentials against the AWS API using `aws sts get-caller-identity`.

Applied Defense Control: GitHub Secret Scanning & Pre-commit Hooks

GitHub automatically identified the secret before code was pushed, blocking the commit. Even if pushed, GitHub Secret Scanning notified AWS, revoking the compromised key in under 60 seconds.
